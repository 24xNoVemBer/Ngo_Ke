Attempt: prove the demo runs with no network at all (R7.01).
Steps: adb reverse tcp:8085 tcp:8085 (so the dev bundle is served over USB), then
airplane mode on (Wi-Fi disabled), then open exp://127.0.0.1:8085 in Expo Go.

Result: the project fails to load with
  Uncaught Error: java.io.IOException: Failed to download remote update
shown in the Expo Go error log. Expo Go downloads a remote update before it
reads the dev server, so it needs internet even though the app data does not.

Conclusion: true offline cannot be demonstrated with Expo Go. A standalone
build (expo run:android / development build) would be needed, which is a
scope decision for the user. What is proven instead: demo reads the bundled
fixture, needs no API, server or key, and was verified with the local
verification server stopped.
